# 若琳AI送（销）货单管理系统 · 单机版

一套**纯 PHP**的送（销）货单开票系统：开票、打印、票据留存、历史单管理、导入老票、CSV 导出，一站式搞定。

> **不需要数据库，不需要 Composer，不需要任何第三方库或插件** —— 数据以 JSON 文件保存，票据以 HTML 存档。

---

## ⚠️ 部署必看：目录所有者必须是 `www`（云服务器）

宝塔上传的文件夹默认属主是 `root`，而 PHP 以 `www` 用户运行，不改所有者**开票一定保存失败**。

1. 宝塔 → 文件 → 进入站点目录
2. `票据留存` 文件夹 → 权限 → **所有者 `root` 改成 `www`** → 勾选「应用到子目录」→ 应用
3. **站点根目录再做一遍**
4. 开一张测试单验证：能正常生成即配好（失败时系统会弹出一页说明，直接指出具体不可写的目录）

SSH 命令等价写法：

```bash
chown -R www:www /www/wwwroot/你的站点目录
chmod -R 755 /www/wwwroot/你的站点目录
```

本地 Windows 运行（phpStudy / XAMPP / php 内置服务器）无此问题。

## 快速开始

### 方式一：Windows 本机运行（最简单）

1. 安装 PHP（或使用 phpStudy / XAMPP 自带的 PHP）
2. 双击启动（在本目录打开命令行）：

```bat
php -S 127.0.0.1:8899
```

3. 浏览器打开 `http://127.0.0.1:8899/ticket.php` 即可开票

### 方式二：云服务器 / 宝塔

1. 宝塔 → 网站 → 添加站点（纯 PHP 即可，PHP 版本选 7.4+）
2. 把本目录**全部文件**上传到站点根目录
3. 按「部署必看」把目录所有者改为 `www`
4. 浏览器访问 `http://你的域名/ticket.php`

> 详细步骤、端口清单、常见问题排错见 **[部署说明.md](部署说明.md)**。

## 功能一览

- **开票**：收货单位、货物明细（多行增删）、制票人/送货人（常用名单，第一位为默认值）、合计自动算、大写金额自动生成
- **票据留存**：开票即生成独立 HTML 存档（按日期分目录），**开票后信息锁定**，改品牌/Logo 不影响历史票
- **历史单**：按开票时间倒序，只显示最近 10 张，单号/收货单位可搜出全部；每行「查看/打印 · 复制重开 · 下载 · 打开位置 · 删除」，支持**复选框批量删除**
- **导入老票**：上传已开好的 `.html` 票据（Ctrl 多选）或扫描留存目录，重复单号自动跳过；导入票的品牌与时间锁定
- **CSV 导出**：按**开票日期区间**导出（紧挨「导入票据」，留空 = 全部），文件名自带区间，Excel 打开不乱码
- **统计**：今日金额 / 累计金额，只按**开票时间**统计
- **手机适配**：首页、票据页、登录页均已适配手机浏览器
- **安全**：CSV 公式注入防护、目录访问防护（.htaccess）、文件锁防并发
